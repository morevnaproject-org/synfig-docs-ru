# Анимация методом «Перекладка»

Анимация методом **Перекладка** — это техника создания анимации, основанная на последовательном перемещении объектов по **Рабочей области**.

#### Этапы создания перекладной анимации:

1. Создайте объекты, которые будете анимировать.
2. Перейдите в **Режим анимации**.
3. Выберите кадр, с которого хотите начать анимацию, и установите объект в изначальное положение.
4. Перемещайте объект на разных кадрах.
5. Все изменения будут записываться на **Шкале кадров** в виде **фиксаторов**.

Все действия будут записываться на шкале времени в виде [фиксаторов.](../osnovnye-principy/fiksatory.md)
