# Time Loop

Преобразование в параметре **Глубина Z** добавляет четыре подпараметра:

* **Связь**
* **Время связывания**
* **Локальное время**
* **Длительность**

Этот конвертер работает аналогично слою **Петля времени**, но влияет только на один параметр.

Для любого целого значения `n` из диапазона:

`Локальное время + abs(продолжительность) * n`\
до

`Локальное время + abs(продолжительность) * (n + 1)`

результирующее значение параметра такое же, как у параметра `Ссылка`, если изменить параметр **Время связывания** на **Время связывания + длительность**.

Другими словами, значения параметра `Ссылка` на протяжении `Длительность` секунд, начиная с **Время связывания**, повторяются циклически. Значение параметра `Ссылка` в момент времени **Время связывания** соответствует результирующему значению в момент `Локальное время`.

**Пример:**\
Если параметр `Ссылка` равен `time` (текущее время), то при `0s` значение равно `0`, а через `10s` значение равно `20`.

**Пример использования конвертера с циклическим повторением:**

Пусть установлены следующие значения:

* **Время связывания** = 5 секунд
* **Локальное время** = 2 секунды
* **Длительность** = 4 секунды

Тогда результирующее значение параметра повторяется циклически, беря значения из параметра **Ссылка** за период **Время связывания + Длительность**.

Пример расчёта для каждого локального времени:

| Локальное время | Результирующее значение | Примечание                                             |
| --------------- | ----------------------- | ------------------------------------------------------ |
| 0 s             | 14                      | Значение `Ссылка` через 7 s                            |
| 1 s             | 16                      | Значение `Ссылка` через 8 s                            |
| 2 s             | 10                      | Значение `Ссылка` при 5 s (учёт Время связывания)      |
| 3 s             | 12                      | Значение `Ссылка` при 6 s                              |
| 4 s             | 14                      | Значение `Ссылка` через 7 s                            |
| 5 s             | 16                      | Значение `Ссылка` через 8 s                            |
| 6 s             | 10                      | Значение `Ссылка` при 5 s (Длительность = 4 s, повтор) |
| 7 s             | 12                      | Значение `Ссылка` при 6 s                              |

Если параметр **Длительность** равен нулю, результирующее значение равно значению параметра **Ссылка** без изменений.

Если параметр **«Длительность»** имеет отрицательное значение, результирующее значение в `Локальное время` по-прежнему соответствует значению параметра **Ссылка** в **Время связывания**, но анимация идёт в обратном направлении.

**Пример:**

Пусть установлены значения:

* **Время связывания** = 5 секунд
* **Локальное время** = 2 секунды
* **Длительность** = -4 секунды

Результирующие значения параметра будут:

| Локальное время | Результирующее значение | Примечание                                        |
| --------------- | ----------------------- | ------------------------------------------------- |
| 0 s             | 6                       | Значение `Ссылка` через 3 s                       |
| 1 s             | 4                       | Значение `Ссылка` при 2 s                         |
| 2 s             | 10                      | Значение `Ссылка` при 5 s (учёт Время связывания) |
| 3 s             | 8                       | Значение `Ссылка` при 4 s                         |
| 4 s             | 6                       | Значение `Ссылка` при 3 s                         |
| 5 s             | 4                       | Значение `Ссылка` при 2 s                         |
| 6 s             | 10                      | Значение `Ссылка` через 5 s (повтор)              |
| 7 s             | 8                       | Значение `Ссылка` при 4 s                         |

{% hint style="info" %}
Этот конвертер можно использовать для всех типов значений.
{% endhint %}
