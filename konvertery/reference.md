# Reference

Преобразование в параметре **Глубина Z** добавляет один подпараметр **Связь**:

Похоже, что этот тип преобразования не выполняет никаких действий, кроме добавления дополнительного параметра.

Любое значение, введённое в **Связь**, становится значением преобразуемого параметра.

Единственный сценарий применения этого типа преобразования может быть следующим:

1. Вы знаете, что точка `A` должна следовать за точкой `B`, поэтому экспортируете точку `B` и подключаете к ней точку `A`.
2. Вы ещё не уверены, как именно должна перемещаться точка `B`, и экспериментируете с различными типами преобразований для неё.
3. Изменение типа преобразования для точки `B` разрывает соединение, установленное на первом шаге.

Чтобы избежать этого, точку `B` следует преобразовать в качестве эталонной. После этого можно экспериментировать с различными преобразованиями внутри неё.

Параметр **Ссылка** позволяет точке `A` оставаться соединённой с точкой `B` и сохранять это соединение во время экспериментов.
