# Установка версии для macOS

Чтобы установить программу на операционную систему macOS, необходимо перейти на сайт [https://synfig.ru/](https://synfig.ru/) и нажать кнопку **Загрузить**.&#x20;

На странице загрузки выберите опцию **macOS** и нажмите кнопку **Скачать**.

В открывшемся окне введите свою электронную почту, чтобы скачать программу и подписаться на уведомления о новых версиях. Либо нажмите на нижнюю кнопку, чтобы просто скачать инсталлятор.

После завершения загрузки откройте скачанный файл `.dmg`.

<figure><img src="https://lh7-rt.googleusercontent.com/docsz/AD_4nXdBF7WsIeZb6XogLv4TZaOkvP06FbzjbixDmgnH8Rn62mR2Ucpb-h9ATJSd8pN7RzijZKv9GndEgm1PaEa8mdq_fy7QocaUyopS4REbz1-Z1n7Z-rH86wY49TM_nibhG6-yUSOyjw?key=sKkdCyjoRpPMlPCIQj2MCGXY" alt=""><figcaption></figcaption></figure>

Перетащите значок Synfig в каталог **Программы** (_Applications_) и дождитесь завершения процесса копирования.

<figure><img src="https://lh7-rt.googleusercontent.com/docsz/AD_4nXereZ7a5mWoK9-K0kyoywA5qnEJMgmFczAS2hOkxNcP0e8rDZIuOcOmm9Exz25oOJlSlAP0fpilRQazG64ilT5x5OO7mq3iWS3DRoWoRKFH6O6B3CAHa4VzLZyi0BoVa3zoPVBvhw?key=sKkdCyjoRpPMlPCIQj2MCGXY" alt=""><figcaption></figcaption></figure>

Запустите Synfig из каталога **Программы** (_Applications_).

На новых версиях macOS при попытке запуска может появиться ошибка:

**«Файл SynfigStudio.app невозможно открыть, так как Apple не может проверить его на наличие вредоносного ПО»**.

<figure><img src="https://lh7-rt.googleusercontent.com/docsz/AD_4nXfJuwQNXvnSRZuwSA6a9zFbidU8UoQew45PHP7q6Z9jVM7tvJTPEYZjUwMdEG5hlXAoQB20zeMaQWGG3zrtLzU5FRP2YOes78vQtOAM9gkEj4VaS8k-UgbpMt7OAechENSzB-127w?key=sKkdCyjoRpPMlPCIQj2MCGXY" alt=""><figcaption></figcaption></figure>

В этом случае выполните следующие действия:

* Откройте каталог **Программы** (_Applications_) через Finder.
* Удерживая клавишу **Command**, щёлкните по значку приложения.
* В появившемся контекстном меню выберите **Открыть**

<figure><img src="../.gitbook/assets/изображение (4).png" alt=""><figcaption></figcaption></figure>

* Нажмите **Открыть**.&#x20;

{% hint style="info" %}
Приложение сохраняется в списке исключений из настроек безопасности, и его можно в любой момент открыть двойным нажатием, как любое обычное приложение. Более подробная информация доступна по ссылке - [https://support.apple.com/ru-ru/guide/mac-help/mchleab3a043/13.0/mac/13.0](https://support.apple.com/ru-ru/guide/mac-help/mchleab3a043/13.0/mac/13.0)
{% endhint %}
