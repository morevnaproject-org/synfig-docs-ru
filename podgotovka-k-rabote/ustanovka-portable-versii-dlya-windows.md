# Установка portable-версии для Windows

**Portable-версия** — это альтернативный способ установки программы на операционную систему Windows. В этом случае программа предоставляется в формате архива `zip`, который не требует запуска инcталлятора.

**Преимущества**:

* Для установки и запуска не требуются права администратора.
* Программа можно распаковать на внешний носитель (например, USB-флешку) и запускать напрямую с него.
* Portable-версия не вносит изменений в системные компоненты операционной системы (системный реестр, системные папки и т. п.).

**Недостатки**:

* Файлы документов Synfig с расширениями `.sif` и `.sifz` не открываются автоматически по двойному щелчку мыши.
*   При необходимости ассоциации файлов с portable-версией программы требуется настраивать вручную.



## Как настроить ассоциацию вручную?

Нажимаем правой кнопкой мыши на нужный файл с расширением `.sif` и `.sifz`. Из выпадающего меню выбираем **Открыть с помощью** → **Выбрать другое приложение**.

Далее откроется окно с выбором приложения. Жмём **Выберите приложение на компьютере**.

Затем необходимо перейти в папку с программой по пути, указанному при распаковке архива. В приведённом примере Synfig был распакован в каталог `SynfigStudio`.

Далее выполните следующие шаги:

* Откройте подкаталог `bin`.
* Найдите файл `synfigstudio.exe`.
* Выберите данный файл в окне выбора приложения и нажмите кнопку **Всегда**.

После этого файлы Synfig будут открываться в программе по умолчанию.

<figure><img src="https://lh7-rt.googleusercontent.com/docsz/AD_4nXdrrV4hwOGYvyJZj4AtnIGkbiCy-DFTuyPwAW-VbXytTXw9xyfUNrcafDPq0BIzB7jT5B1QTSQOH_9ZBjUXUvRyfgiijtCXtPf9yHzpmCQbmeIMENkljYqAwr3jA5ZOnX1GkwB-hA?key=wlyPy0oycuBVBZ7qetwTl-dN" alt=""><figcaption></figcaption></figure>

Чтобы установить portable-версию Synfig, выполните следующие действия:

* Перейдите на официальный сайт Synfig: [`https://synfig.ru/`](https://synfig.ru/).
* Нажмите кнопку **Загрузить**.
* На странице загрузки выберите опцию **Windows (zip)** и нажмите кнопку **Скачать**.
* В открывшемся окне:
  * введите адрес электронной почты, чтобы скачать программу и подписаться на уведомления о новых версиях,
  * либо нажмите нижнюю кнопку, чтобы скачать portable-версию без подписки.

После завершения загрузки распакуйте скачанный архив `zip` в удобное для вас место на компьютере.

{% hint style="danger" %}
Убедитесь, что в пути к папке, куда была распакована программа, используются только буквы латинского алфавита!  При наличии в пути к этой папке букв других языков (например, русского) программа не запустится корректно после распаковки.
{% endhint %}

Для запуска программы дважды щёлкните файл `synfigstudio.bat` .

{% hint style="info" %}
Система может распознать программу как неопознанное приложение. Не беспокойтесь: нажмите ссылку **Подробнее**, а затем – кнопку **Выполнить в любом случае**. Окно примет вид, представленный на скриншоте ниже. Программа находится в стадии получения сертификата, поэтому такая реакция системы при запуске инсталлятора ожидаема.
{% endhint %}
