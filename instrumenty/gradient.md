# Градиент

**Градиент** — инструмент для создания плавных переходов между цветами. Создается как отдельный слой, который можно комбинировать с другими объектами с помощью **Режимов смешивания**.<br>

<figure><img src="../.gitbook/assets/изображение (14).png" alt="" width="32"><figcaption></figcaption></figure>

**Чтобы активировать инструмент:**

* Выберите его на **Панели инструментов**;
* Или нажмите горячую клавишу `g`.

**Порядок работы:**

1. Создайте слой градиента на **Рабочей области**.
2. Используйте контрольные точки для настройки:
   * **Размера** и **положения** градиента;
   * **Угла поворота**;
   * **Радиуса** (для радиальных градиентов).

Доступные настройки для инструмента «**Градиент**»:

* **Имя**
* **Метод смешивания**
* **Непрозрачность**
* **Тип слоя**
