# Деформация по кривой

![](<../.gitbook/assets/layer_distortion_curvewarp_icon (3).png>)

Слой **Деформация по кривой** искажает объект, который изначально лежит по прямой линии, в изогнутую кривую Безье.&#x20;

Каждая точка исходной области определяется двумя перпендикулярными значениями координат, основанными на положении и длине исходной прямой линии. Эти координаты аналогичны координатам `X` и `Y` масштабированной и повернутой двумерной системы координат.

На рисунке ниже представлено графическое отображение слоя «Деформация по кривой».

* Под цифрой `1` — прямая с вершинами, которая отвечает за размер и расположение объекта, на который она влияет.
* Под цифрой `2` — кривая Безье, с помощью которой можно изгибать объект.
