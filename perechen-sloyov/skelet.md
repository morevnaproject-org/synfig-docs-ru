# Скелет

<img src="../.gitbook/assets/layer_other_skeleton_icon.png" alt="" data-size="original">

Скелет — это слой который помогает управлять более сложными объектами с помощью **костей**.

**Параметры слоя Скелета:**<br>

| Имя                                                                                                                                                                           | Значение           | Тип    |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ | ------ |
| ![Type real icon.png](/assets/images/16px-Type_real_icon.png) Глубина Z      | 0.000000           | real   |
| ![Type real icon.png](/assets/images/16px-Type_real_icon.png) Непрозрачность | 0.500000           | real   |
| ![Type string icon.png](/assets/images/16px-Type_string_icon.png) Имя    | skeleton           | string |
| ![Type list icon.png](/assets/images/16px-Type_list_icon.png) Кости          | list (Static List) | list   |

{% hint style="info" %}
Подробнее о работе данного слоя смотрите статью «_Создание скелета_»  в разделе «_Скелетная анимация_»_._
{% endhint %}
