# Импорт изображения

<img src="../.gitbook/assets/layer_other_importimage_icon (1).png" alt="" data-size="original">

После импорта ваши изображения начинают отображаться на **Панели слоев** с помощью данного слоя. Он автоматически помещается  в папку-переключатель.

**Параметр** «**Смещение во времени**»

Смещение времени, используемое для импорта изображений и их последовательности.   Переключение кадра задерживается до установленного кадра в столбце «значение».
