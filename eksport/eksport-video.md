# Экспорт видео

**Рендеринг** — это визуализация (конвертирование) готовой анимации в формат **видеоролика** или серии **изображений**.

![](https://lh7-us.googleusercontent.com/kTYwUraBI8kj83clUgg4txHVOE4VlGyw-atST0FX-Cj5l7O8rx-KkSjCknBXDK47npWARZSGnGXpZ_hX-laSjv3nqKe93JmcShDeaC1B6mINF-qQMlezAxMKYprq8e4vvK15wNE8uh4jmXPnJe74LoU)  — Чтобы запустить рендеринг, щёлкните на кнопку «**Вызвать диалоговое окно параметров визуализации**».

После этого откроется диалоговое окно «**Параметры визуализации**».

**Рендеринг в AVI**

Чтобы выполнить рендеринг анимации в формате `avi`, в поле «**Имя файла**» введите название вашего ролика, например: `first-animation.avi`.

Чтобы выбрать путь для сохранения файла, нажмите кнопку «**Выбрать**» и укажите нужную директорию.

{% hint style="info" %}
По умолчанию **Synfig** кодирует вашу анимацию кодеком `H.264`, применяя сжатие без потерь. Этот формат идеально подходит, если вы планируете вставить отрендеренную анимацию в видеоредактор для дальнейшей сборки сцен и наложения звука.
{% endhint %}

Если вы захотите выбрать другой кодек, выполните следующие действия:

1. В строке «**Цель»** выберите пункт **ffmpeg**. После этого станет активной кнопка **«Параметры»**.
2. Нажмите на **«Параметры»** — откроется диалоговое окно, в котором можно выбрать подходящий кодек.
3. В этом же окне можно задать **размер изображения**.
4. На вкладке **«Время»** можно указать диапазон кадров, который вы хотите отрендерить.

<figure><img src="../.gitbook/assets/60.png" alt=""><figcaption><p>Вкладка «Время»</p></figcaption></figure>

Щелкните **«Визуализация»** и не закрывайте программу, пока не появится надпись **«Файл успешно визуализирован»**, а в панели **«Инфо»** не загрузится полоса 100%. Если вы все сделали правильно, в назначенной папке появится ваш файл.
