# Экспорт Gif-анимации

![](https://lh7-us.googleusercontent.com/kTYwUraBI8kj83clUgg4txHVOE4VlGyw-atST0FX-Cj5l7O8rx-KkSjCknBXDK47npWARZSGnGXpZ_hX-laSjv3nqKe93JmcShDeaC1B6mINF-qQMlezAxMKYprq8e4vvK15wNE8uh4jmXPnJe74LoU)— Чтобы запустить рендеринг, щёлкните на кнопку **«Вызов диалогового окна параметров визуализации»**.\
После этого откроется диалог **«Параметры визуализации»**.

Чтобы отрендерить проект в виде GIF-анимации, в поле **«Имя файла»** укажите имя файла с расширением `gif` и выберите модуль вывода **«magick++»**.\
После завершения рендеринга результат появится в назначенной папке.
